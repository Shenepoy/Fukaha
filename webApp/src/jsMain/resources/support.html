Fukaha support

Help with clean links, preview sources, and sharing.

Englishالعربية

Found a problem or have a question?

Contact the maintainer on GitHub →

Include your platform, Fukaha version, what you expected, and what happened. Use a public example link. GitHub issues are public; omit passwords, API keys, private links, and personal information.

Clean your first link

Paste a link into Fukaha, or share it from another app using the system share sheet. Choose Clean link to remove supported tracking parameters, or Embed link to use a preview source. Copy or share the result.

A preview is missing or a source is unavailable

Preview sources are independent services, and receiving apps decide how previews appear. Try another source for that platform in Settings, or share the clean link. A successful connection check does not guarantee that a particular link has a preview. Use the source-check refresh control in Settings to check availability. On iOS, this control is available starting with version 26.10.0; older builds support source selection only.

Find the iOS share extension

Open Safari's share sheet. Look for Fukaha in the app row, using More to find additional apps. The action list also offers Clean with Fukaha; use Edit Actions if you need to enable it. Open Fukaha once to choose your preferred behavior.

Media downloading needs a server

Native media downloading requires your own compatible Cobalt server over HTTPS, plus an API key if your server requires one. Configure it under Media download. No working server is included, and the web app does not download media. Clean and embed links work without a download server.

Clear saved data

Use the native app's cache controls to remove downloaded media. To reset web preferences and offline files, clear site data for fukaha.shenepoy.com in your browser. See the privacy policy for other storage and deletion details.

TestFlight feedback

For an iOS beta, use Send Beta Feedback in Apple's TestFlight app. Describe the steps and check screenshots for private content before sending. For general questions, use the GitHub contact link above.

Privacy questions

Contact the maintainer through the issue tracker with a general description. If your request needs sensitive information, ask to arrange a private follow-up before posting it.

دعم Fukaha

مساعدة في تنظيف الروابط ومصادر المعاينة والمشاركة.

لديك سؤال أو واجهت مشكلة؟

تواصل مع المطوّر عبر GitHub ←

اذكر المنصة وإصدار التطبيق والخطوات والنتيجة المتوقعة والفعلية. استخدم رابطًا عامًا كمثال. البلاغات عامة؛ لا تنشر كلمات مرور أو مفاتيح API أو روابط خاصة أو معلومات شخصية.

تنظيف أول رابط

الصق الرابط في Fukaha، أو شاركه من تطبيق آخر عبر قائمة المشاركة. اختر «رابط نظيف» لإزالة معاملات التتبّع المدعومة، أو «رابط معاينة» لاستخدام أحد مصادر المعاينة، ثم انسخ النتيجة أو شاركها.

المعاينة لا تظهر أو المصدر غير متاح

مصادر المعاينة خدمات مستقلة، والتطبيق المستقبِل يقرر طريقة عرضها. جرّب مصدرًا آخر للمنصة من الإعدادات، أو شارك الرابط النظيف. نجاح الاتصال لا يضمن وجود معاينة لرابط معين. استخدم زر إعادة فحص المصادر في الإعدادات للتحقق من توفرها. يتوفر هذا الزر على iOS بدءًا من الإصدار 26.10.0؛ أما النسخ الأقدم فتدعم اختيار المصدر فقط.

إظهار امتداد المشاركة على iOS

افتح قائمة المشاركة في Safari وابحث عن Fukaha ضمن صف التطبيقات، واستخدم «المزيد» لإظهار التطبيقات الأخرى. يتوفر أيضًا الإجراء «Clean with Fukaha» ضمن قائمة الإجراءات؛ استخدم تعديل الإجراءات لتفعيله عند الحاجة. افتح Fukaha لاختيار إعدادات المشاركة المفضلة.

تحميل الوسائط يحتاج إلى خادم

تحتاج ميزة التحميل في التطبيق الأصلي إلى خادم Cobalt متوافق خاص بك عبر HTTPS ومفتاح API إذا كان الخادم يطلبه. أدخل الإعدادات ضمن تحميل الوسائط. لا يوجد خادم جاهز مضمّن، ولا يدعم تطبيق الويب تحميل الوسائط. يمكنك تنظيف الروابط وإعداد روابط المعاينة دون خادم تحميل.

حذف البيانات المحفوظة

استخدم أدوات مسح الذاكرة المؤقتة في التطبيق لحذف الوسائط. لإعادة ضبط إعدادات الويب وملفاته، امسح بيانات موقع fukaha.shenepoy.com من المتصفح. راجع سياسة الخصوصية لتفاصيل التخزين والحذف.

ملاحظات TestFlight

لإرسال ملاحظات النسخة التجريبية على iOS، استخدم إرسال ملاحظات الإصدار التجريبي في تطبيق TestFlight من Apple. اشرح خطوات المشكلة وتأكد من خلو لقطات الشاشة من المعلومات الخاصة قبل إرسالها. للأسئلة العامة، استخدم رابط GitHub أعلاه.

أسئلة الخصوصية

ابدأ بطلب عام عبر بلاغات GitHub. إذا احتجت إلى إرسال معلومات حساسة، اطلب ترتيب متابعة خاصة قبل نشرها.
